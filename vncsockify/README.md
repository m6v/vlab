# Universal HTML5 Web Console & Gateway Engine

Программный комплекс на Python для организации безопасного удаленного доступа к консолям виртуальных машин и серверов через браузер (HTML5 noVNC) с поддержкой динамической авторизации по токенам и автоматического управления питанием бэкендов.

## Архитектура системы

Комплекс состоит из двух независимых взаимодействующих серверных компонентов:
1. `vncsockify.py` — сетевой асинхронный транспортный шлюз, обеспечивающий бесшовную трансляцию сырых графических потоков VNC/RFB в веб-сокеты браузера.
2. `webview-server.py` — управляющий веб-сервер и координатор сессий, обеспечивающий раздачу статических ресурсов интерфейса noVNC, обрабатоку REST API запросов состояний (`/status`, `/start`) и динамическую генерацию уникальных фавиконок для целевых хостов из `/usr/share/pixmaps`.

## Требования и зависимости

* интерпретатор Python 3
* библиотека `websockets` (рекомендуется v15.0+ для актуальных версий Python или v11.0.3 для сред с Python 3.7)
* пакет `novnc` (для раздачи базовых JS-декодеров из `/usr/share/novnc/`)
> Если в системе отсутствуют готовые пакеты websockets и novnc, их скачивают из github, novnc распаковывают в `/usr/share`, а websockets в `/srv/qemu` или `/usr/local/lib/python3.7/dist-packages`

## Установка и сборка

Проект оснащен универсальными `Makefile`, автоматизирующими компиляцию deb-пакетов, которые устанавливают в систему.

## Ручной запуск компонентов

Для запуска служб из терминала используют команды

```bash
# Запуск управляющего сервера консоли (порт 8081)
webview-server.py 0.0.0.0:8081 --proxy-port=8080 --config-dir=/srv/qemu/config --novncroot=/usr/share/novnc/

# Запуск транспортного вебсокет-моста (порт 8080)
./vncsockify.py 0.0.0.0:8080 --token-source=/srv/qemu/tokens.conf
```

После старта интерфейс управления и отображения экранов доступен в браузере по адресу:
`http://<IP_СЕРВЕРА>:8081/?vm=ИМЯ_МАШИНЫ`

## Интеграция с Systemd

При установке через `make deb` компоненты автоматически регистрируются в системе как фоновые демоны.

```bash
# Старт и активация автозапуска экосистемы vnc2ws
sudo systemctl enable --now webview-server.service
sudo systemctl enable --now vncsockify.service

# Проверка статуса сетевых воркеров
sudo systemctl status webview-server.service vncsockify.service
```
